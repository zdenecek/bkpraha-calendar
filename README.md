
# BK Praha Calendar

## Requirements

- PHP 7.4

## Embedding

```html
<div class="h_iframe">
  <iframe
    src="https://calendar.bkpraha.cz/api/?view=column&bg=%23ECEFF1"
    frameborder="0"
    allowfullscreen
  ></iframe>
</div>

<style>
  .h_iframe iframe {
    width: 100%;
    height: 1090px;
  }
  .h_iframe {
    height: 100%;
    width: 100%;
  }
</style>
```
